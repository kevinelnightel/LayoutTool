# LayoutTool 使用教程

> PDMS 二维出图插件 · 操作手册（2026-11 版）

## 快速开始

1. 把 `LayoutTool` 目录放进 `%PMLLIB%`（例如 `E:\AVEVA\Addin\PMLLIB\LayoutTool`），确认 `%PMLLIB%` 含其上级目录。
2. PDMS 里加载表单：`pml reload form !!LayoutToolMain`；改了 `.pmlobj` 后 `pml reload object <类名>`。
3. Config 页选切图范围 → 设类型/图幅/比例 → 点 **Generate**；Export 页把图纸加入列表后导出。

## 附录 A · Drawlist 配置的保存与加载

- Export：把当前 DrawList / RemoveList / 每个视图的配置写成 XML，便于下次复用。
- Load：读回之前导出的 XML，自动填充列表与视图配置；点视图前先加载一次。
- 文件格式：全局清单 + 每视图一行；视图专属清单按项逐条记录，避免单行过长写不进文件。
- 老版本导出的配置仍可加载：缺新字段时保持默认，不覆盖当前设置。
- 保存路径建议放 %PDMSUSER% 下的项目目录，别放安装目录，避免权限与占用问题。

> 导出提示 (41,319) 无法访问文件时：换新文件名或新目录再试——通常是文件被占用或路径不可写，不是权限不足。

## 附录 B · 哪些类型可以加入 Drawlist

- 容器 / 区域：SITE、ZONE、STRU、EQUI、PIPE、GPWL、GPSET、REST、HVAC
- 结构件：FRMW（框架）、SBFR（子框架）、SCTN（型材截面）、GENSEC（通用截面）
- 加入的是「显示范围」：只决定图上出现什么，不等于自动生成标注或表格行。
- 不需要的内容加到下面的 RemoveList，导出时会从显示范围里剔除。
- 管口方位图：一个视图只放一台设备，不要把整个区域塞进 ADDE。

> 方位图 ADDE 放区域会带出多台设备，表现为锚点重名 (41,12) 或尺寸链重复。

## 附录 C · 性能与常见问题

- 卡在「优化标注」：先看障碍物类型是否太多——管线、阀门、仪表、三通、弯头通常够用，设备轮廓可按需关闭。
- 管线障碍默认取包围盒；图很大时可退回中线模式，避让薄一点但快很多。
- 标注多时优先用 Near 自动算比例，减少手工微调；密集区允许轻微贴边，别一味追求零重叠。
- 报 (41,12) Name ... already used：同名注记或锚点残留，删掉旧注记或重开视图后重生成。
- 报 (41,319) 无法访问文件：配置文件被占用或目录不可写，换路径。
- 生成前先点一下图纸列表读取配置，再点 Generate，避免用到上一张图的旧参数。

> 出图慢优先查「取数范围」而不是「排布算法」：范围越精确，标注越少，整体越快。
